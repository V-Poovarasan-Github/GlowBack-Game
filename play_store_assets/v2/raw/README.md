# Raw screenshots (real renders of the app's own UI)

These 7 PNGs are generated by `StoreScreenshotTest` from GlowBack's real Compose screens with fictional demo data
(player NOVA; rivals ARJUN, MEERA, KABIR, NISHA, ROHAN, ZARA). Nothing is hand-drawn or AI-generated.
They have no Android status bar, and the two dialog shots (`02_setup`, `03_share`) are the real dialog window over the real dimmed screen.

Regenerate (skipped in normal test runs):
    STORE_SCREENSHOTS=true gradle :app:testDebugUnitTest --tests com.example.StoreScreenshotTest --rerun-tasks --console=plain
Then frame them with captions:
    python3 ../source/build_screenshots.py      # writes ../screenshots/*.png (1080x1920)

The raw files are taller than Google Play allows (max 2:1); upload only the framed files in `../screenshots/`.
